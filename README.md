# Jarvis

Локальный голосовой ассистент на русском для слабого железа (целевая платформа —
мини-ПК на **Intel N100**, 8 ГБ shared RAM). Всё работает офлайн и суверенно:
ничего не уходит в облако.

```
речь  ─►  Vosk (STT)  ─►  лестница распознавания L0→L3  ─►  действие + голос
                              │                               │
                   детерминированные слои            Qwen2.5-3B (llama.cpp)
                   (alias/pattern/fuzzy/                native function calling
                    semantic) — без LLM                только на «хвосте»
```

- **Слух** — Vosk (small ru), эхо-гейт против само-триггера.
- **Мозг** — Qwen2.5-3B-Instruct в отдельном процессе `llama-server` (Vulkan/iGPU),
  Python весов не держит. Эмбеддинги памяти — второй лёгкий `llama-server --embedding`.
- **Руки** — каталог протестированных навыков (KDE Plasma, диагностика, разведка),
  а не bash «на лету». `execute_bash` — gated-fallback через песочницу.
- **Голос** — Piper + DSP-цепочка sox под «кино-Джарвиса».
- **Память** — ChronoMemory (Chroma), ночная консолидация фактов об операторе.
- **HUD** — живой оверлей на Qt (Wayland layer-shell), пульсирует в такт голосу.

## Быстрый старт

Единая точка входа — `./jarvis` (локализована на русском):

```bash
./jarvis setup      # поставить/докачать всё, чего нет (пакеты, venv, сборка, модели, юниты)
./jarvis test       # сквозная диагностика без изменений, с вердиктом ✓/⚠/✗
./jarvis run        # авто-починка + поднять оба llama-server + ассистент (foreground)
./jarvis help       # все команды (status/stop/logs/restart/toggle/wipe-memory)
```

Тонкие тумблеры под N100 (KV-quant, спекуляция, стриминг, wake-word, L2-семантика)
выключены по умолчанию — включаются осознанно через `./jarvis toggle` или env.
Подробности и таблица — в [`src/README.md`](src/README.md).

## Безопасность исполнения

- Любая bash-команда от модели сначала идёт в **песочницу** (bwrap/podman),
  затем — на исполнение. Песочница проверяет синтаксис и доступность бинарей,
  но не гарантирует поведение сетевых/пишущих команд на реальном хосте.
- **Разрушительные** команды и навыки требуют голосового подтверждения
  **кодовой фразой целиком** (по умолчанию «Джарвис, подтверждаю»;
  меняется через `JARVIS_CONFIRM_PHRASE`) — защита от ошибок распознавания Vosk.
- Разведывательные навыки (`nmap` и пр.) — для **авторизованного** тестирования
  собственной сети. Используйте ответственно.

## Архитектура

Полное описание модулей, лестницы распознавания, self-authoring навыков,
самолечения, памяти и HUD — в [`src/README.md`](src/README.md).

```
src/core/        оркестрация, точка входа, супервизор/бессмертие
src/inference/   клиент llama-server, роутер интентов, агентный цикл, эмбеддинги
src/skills/      каталог навыков, паттерны, макросы, learning/healing
src/services/    фоновые демоны (sentinel, recon, watch)
src/memory/      ChronoMemory, рефлексия, эфемерное исполнение
src/audio/       Vosk-вход, Piper-выход, FFT для HUD, wake-word
src/ui/          HUD, управление окнами KWin, рендер
src/common/      шина событий, парсер bash, синглтон
```

## Разработка

```bash
pytest tests/     # тесты (конфиг — ./pytest.ini; async через адаптер в conftest)
ruff check .      # линт (конфиг — config/pyproject.toml: E/W/F/I/B/UP)
pre-commit run -a # хуки (ruff --fix, trailing-whitespace, large-files и т.п.)
```

> **Лицензия не указана.** По умолчанию это означает, что все права защищены и
> сторонние лица юридически не вправе использовать, копировать или
> распространять код без явного разрешения автора.
